# Nermyca site v0.1

Статический сайт для GitHub Pages.

## Локальный запуск
Откройте `index.html` напрямую или запустите любой локальный HTTP-сервер.

## Публикация
1. Создать отдельный GitHub-репозиторий (например `nermyca-site`).
2. Загрузить содержимое этой папки в ветку `main`.
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
4. После проверки Pages подключить custom domain `nermyca.com`.
5. В Cloudflare DNS использовать записи GitHub Pages в режиме **DNS only**, без Cloudflare Proxy.

## Важно
В `assets/img/` включены три утверждённых варианта логотипа Nermyca: cyan, white и black. На тёмной версии сайта используется cyan-вариант.

Контакт `contact@nermyca.com` в кнопках — заготовка. Перед публикацией заменить, если этот ящик ещё не создан.
